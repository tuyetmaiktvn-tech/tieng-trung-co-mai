# Tiếng Trung Cô Mai — Version 3.3.2 Lesson 02 Audio Hotfix

## Cách cập nhật
1. Sao lưu thư mục web hiện tại.
2. Chép toàn bộ nội dung gói này vào thư mục gốc của repository.
3. Mở `hsk1-lesson02.html` để kiểm tra.
4. Commit và Push lên GitHub.

## Cấu trúc
- `hsk1-lesson02.html`: trang Bài 2.
- `data/lesson02.json`: dữ liệu JSON.
- `HSK1_Bai2_Kho_du_lieu_goc.xlsx`: dữ liệu Excel gốc.
- `assets/audio/lesson02/*.mp3`: MP3 ưu tiên.
- `assets/js/audio-manager.js`: tự động chuyển sang TTS zh-CN khi MP3 lỗi.
- `assets/js/lesson02.js`: Vocabulary, mẫu câu, hội thoại, flashcards, bài tập.
- `assets/css/lesson.css`: Times New Roman cho tiếng Việt/pinyin; font Hán chuyên dụng.

## Lưu ý
Các tệp MP3 trong gói được tạo tự động bằng giọng tổng hợp Mandarin để bảo đảm hoạt động ngoại tuyến.
