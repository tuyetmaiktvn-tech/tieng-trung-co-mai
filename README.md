# Tiếng Trung Cô Mai – Version 1.0

Bộ mã nguồn website tĩnh, phù hợp để triển khai trên GitHub Pages.

## Cấu trúc
- `index.html`: Trang chủ
- `hsk/`: Các trang HSK 1–6 và bài học mẫu HSK 1 – Bài 1
- `specialized/`: Tiếng Trung thương mại và tiếng Trung đường sắt
- `assets/css/style.css`: Giao diện dùng chung
- `assets/js/app.js`: Chức năng dùng chung
- `data/hsk1.json`: Dữ liệu từ vựng mẫu

## Cách đưa lên GitHub
1. Giải nén file ZIP.
2. Mở repository `tieng-trung-co-mai`.
3. Chọn **Add file → Upload files**.
4. Kéo toàn bộ file và thư mục bên trong thư mục đã giải nén lên GitHub.
5. Chọn **Commit changes**.
6. Đợi GitHub Pages cập nhật khoảng 1–3 phút.

Lưu ý: Hãy tải **các tệp bên trong thư mục**, không tải nguyên thư mục bao ngoài.
