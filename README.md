# Tiếng Trung Cô Mai – Version 1.1

Điểm mới:
- Logo tối giản riêng cho thương hiệu.
- Favicon riêng.
- Menu mới: Trang chủ, HSK, Chuyên ngành, Công cụ, Về Cô Mai.
- Menu xổ xuống trên máy tính và thu gọn trên điện thoại.
- Trang chủ thiết kế lại.
- Bổ sung Tiếng Trung du lịch, Flashcard, Bài tập, Tài liệu, Giới thiệu, Liên hệ.

Cập nhật:
1. Giải nén ZIP.
2. Chép toàn bộ vào Documents\GitHub\tieng-trung-co-mai.
3. Chọn thay thế tệp trùng tên.
4. GitHub Desktop: Commit rồi Push origin.
