# Audio HSK 1 – Bài 1

## Cách sử dụng

Bạn chỉ cần đặt file MP3 vào đúng thư mục và đúng tên. Không phải sửa HTML, JSON hoặc JavaScript.

Website hoạt động theo thứ tự:

1. Có MP3 đúng tên → phát MP3.
2. Chưa có MP3 → dùng giọng đọc tiếng Trung của trình duyệt (TTS) làm phương án dự phòng.

## Thư mục

- `vocabulary/`: âm thanh từ vựng
- `examples/`: âm thanh câu ví dụ
- `patterns/`: mẫu câu và ví dụ ngữ pháp
- `dialogues/`: toàn bài hội thoại và từng câu
- `pronunciation/`: bài luyện phát âm

Danh sách đầy đủ nằm trong file `audio-manifest.json`.

## Ví dụ

- `vocabulary/vocab-01.mp3` → 你好
- `examples/example-01.mp3` → 你好，我是小语。
- `dialogues/dialogue-01.mp3` → toàn bộ Hội thoại 1
- `dialogues/dialogue-01-line-01.mp3` → câu thứ nhất của Hội thoại 1

## Lưu ý kỹ thuật

- Dùng định dạng MP3.
- Khuyên dùng bitrate 96–160 kbps.
- Tên file phải viết thường, không dấu, không khoảng trắng.
- Không đổi tên thư mục.
